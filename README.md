# Data Structures Overview

| Data Structure |  Category  | Internal Implementation                     | What Problem Does It Solve?                          | Related Algorithms |
| :------------- | :--------: | :------------------------------------------ | :-------------------------------------------------- | -----------------: |
| [**Array**](#array) | Linear | Contiguous Memory | Fast indexed and random access |  |
| [**String**](#string) | Linear | Character Array | Efficient text storage and manipulation |  |
| [**Singly Linked List**](#singly-linked-list) | Linear | Nodes with Next Pointer | Efficient insertion and deletion operations |  |
| [**Doubly Linked List**](#doubly-linked-list) | Linear | Nodes with Previous and Next Pointer | Bidirectional traversal and efficient deletion |  |
| [**Stack**](#stack) | Linear | Array or Linked List | Last In First Out processing |  |
| [**Queue**](#queue) | Linear | Linked List or Circular Buffer | First In First Out processing |  |
| [**Double Ended Queue**](#double-ended-queue) | Linear | Doubly Linked List or Circular Buffer | Efficient insertion and deletion from both ends |  |
| [**Hash Map**](#hash-map) | Non-linear | Hash Table with Buckets | Fast key-value lookup |  |
| [**Hash Set**](#hash-set) | Non-linear | Hash Table | Fast uniqueness checking |  |
| [**Heap and Priority Queue**](#heap-and-priority-queue) | Non-linear | Binary Heap implemented using Array | Fast minimum or maximum retrieval |  |
| [**Binary Tree**](#binary-tree) | Non-linear | Node-Based Tree Structure | Hierarchical data representation |  |
| [**Binary Search Tree**](#binary-search-tree) | Non-linear | Ordered Binary Tree | Efficient ordered searching and sorting |  |
| [**Trie**](#trie) | Non-linear | Prefix Tree using Character Nodes | Fast prefix-based searching |  |
| [**Graph**](#graph) | Non-linear | Adjacency List or Adjacency Matrix | Relationship and network modeling |  |
| [**Union Find**](#union-find) | Non-linear | Parent Array with Rank and Path Compression | Efficient connectivity checking |  |
| [**Segment Tree**](#segment-tree) | Non-linear | Binary Tree for Range Queries | Fast range query and update operations |  |
| [**Fenwick Tree**](#fenwick-tree) | Non-linear | Binary Indexed Tree using Array | Efficient prefix sum and cumulative queries |  |
