## Time Complexity Table

| Operation | Average Case | Worst Case | Amortized Case |
| :-------- | :----------: | :--------: | -------------: |

## Space Complexity

## Common Operations

- Push: Add element to top
- Pop: Remove element from top
- Peek: View top element
- isEmpty: Check if stack is empty
- Size: Get number of elements
